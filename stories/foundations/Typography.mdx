# Typography

**Sans:** Inter (`--tj-font-sans`) — body, UI, tables.
**Display:** Faster One (`--tj-font-display`) — logo and hero headings only.

Load fonts with `tajerp_ui/styles/fonts-local.css` (self-hosted, works
offline, includes Cyrillic-ext for Tajik: ӣ ӯ ҳ қ ғ ҷ) or
`tajerp_ui/styles/fonts.css` (Google Fonts). Faster One has no Cyrillic glyphs,
so use it only for Latin display text.

## UI scale (inside components)

Components use a role-based scale with Tailwind utilities. Use these instead of
arbitrary sizes such as `text-[13px]`, so the whole product stays on one
scale. `cn()` knows these utilities and merges them correctly.

0.5.0 raised the scale for readability: body text is 15px (was 13.5px) with a
1.5 line height, and two heading roles were added. Meta text (`text-ink-3`) now
holds 6:1 contrast, so small captions stay readable.

| Utility | Size | Line height | Role |
|---------|------|-------------|------|
| `text-ui-micro` | 11px | 1.5 | compact badges, counters |
| `text-ui-caption` | 12.5px | 1.5 | table heads, meta, timestamps |
| `text-ui-helper` | 13px | 1.5 | helper and error text, toast descriptions |
| `text-ui-label` | 14px | 1.5 | labels, small buttons, breadcrumbs |
| `text-ui-body` | 15px | 1.5 | body text, table cells, menu items, tabs |
| `text-ui-control` | 15px | 1.5 | inputs and default buttons |
| `text-ui-title` | 17px | 1.4 | card and section titles |
| `text-ui-heading` | 20px | 1.3 | page and panel headings |
| `text-ui-display` | 24px | 1.25 | page titles, hero numbers |

### Weight

Calm screens use few weights: regular for text, `font-medium` for names and
values, `font-semibold` for titles, tabs and buttons. `font-bold` is reserved
for the primary (`solid`) button and counters.

## Weights

Available as CSS variables: `--tj-fw-regular` (400), `--tj-fw-medium` (500),
`--tj-fw-semi` (600), `--tj-fw-bold` (700), `--tj-fw-black` (800).
